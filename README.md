## 📖 Overview

**Ella Sri Lanka Travel Guide** is a responsive, multi-page web application designed to showcase the stunning hill country destination of Ella, Sri Lanka. From mist-covered mountains and colonial railway marvels like the Nine Arch Bridge, to ancient heritage sites and hotel reservations, this project provides a complete travel portal for both local and foreign tourists.

Developed with clean semantic HTML, modular CSS styles, and vanilla JavaScript for smooth UI interactions.

---

## ✨ Key Features

- **🏔️ Top Attractions & Hidden Gems (`places.html`)**: Detailed guides for iconic spots including Nine Arch Bridge, Ravana Falls, Little Adam's Peak, and Ravana Cave.
- **🏛️ Cultural Heritage (`heritage.html`)**: Cultural background and historical information on landmark sites such as Narangala Mountain and Dowa Rock Temple.
- **📸 High-Resolution Gallery (`gallery.html`)**: Curated image showcase capturing Ella's green valleys, waterfalls, and scenic viewpoints.
- **🏨 Accommodation Finder (`hotels.html`)**: Hotel listings featuring direct booking links, phone contacts, and ratings.
- **🚨 24/7 Emergency Hotlines (`contacts.html`)**: Organized emergency directory including tourist police, local hospitals, national disaster management, and ambulance services.
- **⭐ Interactive Reviews (`reviews.html`)**: Client-side interactive review submission form allowing users to submit star ratings and comments dynamically.
- **🧭 Dynamic Navigation Bar**: Sticky navbar with smooth scroll-aware padding transition.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/lgihan483-sudo/Travel-guide.git
cd Travel-guide
```

### 2. View locally
No server build steps or node dependencies required. Simply open `index.html` in your favorite web browser:
- Double click `index.html`, OR
- In Visual Studio Code, right-click `index.html` and select **Open with Live Server**.

---

## 🌐 GitHub Pages Deployment

To host this website live on the web for free using GitHub Pages:

1. Push your repository to GitHub.
2. In your GitHub repository, navigate to **Settings** > **Pages** (left sidebar).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/(root)`
4. Click **Save**.
5. Within 1–2 minutes, your website will be live at:
   ```text
   https://lgihan483-sudo.github.io/Travel-guide/
   ```
